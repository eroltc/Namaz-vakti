# Miqat

Luxury Islamic prayer times — elegant, offline-first, multilingual.

## Features

- Prayer times with countdown and progress ring
- Methods: MWL, Egyptian, Karachi, Umm al-Qura, ISNA, Diyanet, Dubai, Kuwait, Qatar, Singapore
- Asr Standard/Hanafi; geolocation + cities; Qibla; Hijri; weekly view
- Spiritual content EN/TR/DE/FR; themes; notifications; localStorage

## Tech

Next.js 15 App Router, TypeScript, Tailwind, adhan, next-intl

## Run

cd namaz-vakti
then: package install, then package script dev
Open http://localhost:3000

Production: package script build, then start

## Methodology

On-device astronomical calculation. Hijri via Intl Islamic calendar.
